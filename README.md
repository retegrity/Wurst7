# Wurst Client v7 (improved by retegrity and Sonnet 5.5)

this is a fork of wurst that i have coded using claude because of my lack of ability to code :sob:

the following hacks have been inspired by or taken from other clients/mods:

- NoJumpDelay from NoJumpDelay Enhanced ([repository](https://github.com/KadTheHunter/NoJumpDelay))
- improved .vclip mechanic from Autism Client ([repository](https://github.com/AutismDevelopment/Autism-Client))
- speedhack's "strafe" was inspired by the strafe hack in LiquidBounce ([repository](https://github.com/CCBlueX/LiquidBounce))

## Installation

so far my fork can be downloaded by cloning the repository and building the mod jar from source, but i will soon begin adding the mod jar to the releases tab for an easier installation
